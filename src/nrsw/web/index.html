How NRSW works

  1. Register the layout

    Mark the field locations on a genuine layout reference. Align documents to that layout and measure how its fields vary across genuine documents.

  2. Learn local evidence

    Mark one or two fields that may have been edited in each forged training document. NRSW compares them with the same fields on genuine documents to learn which changes are associated with forgery.

  3. Score and calibrate

    The classifier uses signed field features, an evidence-weighted summary, peak evidence strength, and global features. A separate genuine set determines the score threshold.
